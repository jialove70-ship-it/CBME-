# AI × CBME｜台中課程心得分享

2026 年 7 月 25 日第三屆臺灣 CBME 醫學教育週的七堂課心得，適合 5–10 分鐘分享。全頁優先使用 Microsoft YaHei（微軟雅黑），提供手機版與列印樣式。

第二頁標示分享者「蘇怡嘉｜教研部／藥學部」。七堂課後新增「把心得帶回工作現場」，以教研部的評量回饋、藥學部的模擬教學及分階段試行整理個人行動方向；此頁列印時獨立成頁。

- GitHub Pages：https://jialove70-ship-it.github.io/CBME-/
- Netlify：https://cbme-ai-jia.netlify.app/

## 現場投票

1. 講者開啟任一網站，使用目前場次或按「建立新場次」。
2. 觀眾掃描 QR code，或使用「複製投票連結」分享的網址。
3. 觀眾選擇答案並送出，講者畫面每 3 秒更新總票數、各選項票數與百分比。

每個瀏覽器以匿名 UUID 識別，同一場次限一票，送出後不能改票。這是瀏覽器識別，並非個人身分驗證；清除儲存資料或換瀏覽器會成為另一個識別碼。新場次使用另一組代碼，保留舊場次結果。可下載統計 CSV。

觀眾頁在開啟及投票後讀取結果，也可手動更新；只有講者頁持續輪詢。斷線時保留上次統計並顯示連線狀態。

GitHub Pages 提供靜態頁面；共用票數由 Netlify Functions 與 Netlify Blobs 儲存。API 允許此網站與指定的 GitHub Pages 來源，不開放任意跨站來源。前端沒有部署憑證。

## 建置與部署

Node.js 22.12 以上：

```sh
npm ci
npm test
npm run build
netlify deploy --no-build --prod --dir public --functions netlify/functions
```

Netlify 建置設定在 `netlify.toml`。使用持久性的 site-wide Blobs store，每票以原子新增避免並行覆寫；結果完整讀取分頁。不能只上傳 HTML 壓縮檔來啟用共用統計。

GitHub Pages：`main` 分支根目錄；需同時發布 `index.html` 與 `vendor/qrcode.js`。更新前端後也須重新部署 Netlify，以保持兩端內容一致。

驗證包含 25 項後端測試、100 筆並行投票、防重送、場次隔離、分頁與指定 GitHub Pages 跨站請求；正式環境已用獨立場次驗證投票與持久統計。
