# AI × CBME｜台中課程心得分享

一頁式繁體中文靜態網頁，整理 2026 年 7 月 25 日第三屆臺灣 CBME 醫學教育週的課程心得，適合 5–10 分鐘分享。

線上閱讀：https://jialove70-ship-it.github.io/CBME-/

## 使用

- 直接用瀏覽器開啟 `index.html`，不需安裝套件或連線至外部服務。
- 依七堂議程順序分享，分別呈現「課程重點」與「我的心得」。
- 首頁提供 HTML 演講的互動開場，可選擇經驗、查看回應及重新選擇。
- 全頁優先使用 Microsoft YaHei（微軟雅黑），並提供系統字型備援。
- 支援手機閱讀、鍵盤操作與瀏覽器列印。

## 部署

GitHub Pages：Deploy from a branch → `main` → `/ (root)`。

Netlify：上傳 `cbme-netlify.zip`；壓縮檔根目錄僅含公開的 `index.html`，不需建置。

## 整理依據

「課程重點」為課程內容整理轉述；「我的心得」與未來試行方向為分享用反思。講者與時段依正式議程標示。

官方主研討會：https://cbme.lib.cmuh.org.tw/p/JUL25-2026
